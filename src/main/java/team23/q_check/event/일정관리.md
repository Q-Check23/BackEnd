1. 연도와 월을 받으면 해당 월에 존재하는, 내가 참가하고 있는 동아리별로 묶어서 일정 정보 응답
- 요청: 연도, 월 정보 포함. 사용자 정보는 access token으로 판별
- 응답: 사용자가 참가할 예정인 행사들의 정보 응답(동아리별로 묶어서) - 행사 이름, 동아리 이름, 장소, 날짜
  - 연도, 월이 과거인 경우 참가했던 행사 정보 응답

2. 행사 검색: 행사, 동아리, 장소 이름에 따라 검색
- 요청: 쿼리
- 응답: 사용자가 참가했던, 또는 참가할 예정인 행사들 중, 행사이름, 동아리 이름, 장소 이름 중 쿼리를 포함하는 행사들 응답

3. 행사 필터링: 기간, 이름, 동아리로 필터링
- 요청: 쿼리파라미터로 기간, 이름, 동아리 중 하나 선택.
  - 기간: 시작 날짜, 끝 날짜
  - 이름: 행사 이름
  - 동아리: 동아리 이름
- 응답: 사용자가 참가했던, 또는 참가할 예정인 행사들 중 필터링한 결과 응답

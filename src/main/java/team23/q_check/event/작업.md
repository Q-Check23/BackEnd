## 작업 이력

### 1. 초기 엔티티 생성 (`c9e05b9`)
- `Event`, `Registration`, `AttendanceLog`, `EventPhoto`, `FormField`, `FormAnswer` JPA 엔티티 생성
- `RegistrationStatus`, `AttendanceMethod`, `FieldType` enum 생성

### 2. 행사 관리 기능 (`6969078`)
- **엔티티 완성:** `Event` (club, title, startTime/endTime, location, registerFee 등)
- **커스텀 폼 필드:** `FormField` (label, fieldType, options JSON, sortOrder, required)
- **API:**
  - `POST /api/events` — 행사 생성 (club ADMIN 이상)
  - `GET /api/events` — 행사 목록 조회 (페이징)
  - `GET /api/events/{eventId}` — 행사 상세 조회 (formFields 포함)
  - `PUT /api/events/{eventId}` — 행사 수정 (club ADMIN 이상)
- **DTO:** `CreateEventRequestDto`, `UpdateEventRequestDto`, `EventDetailResponseDto`, `EventListItemDto`, `EventPageResponseDto`, `FormFieldRequestDto`, `FormFieldResponseDto`

### 3. 참가 신청 기능 (`6088302`)
- **엔티티 완성:** `Registration` (event, user, qrToken, status, registeredAt, registerFeePaid)
- **API:**
  - `POST /api/events/{eventId}/registrations` — 행사 참가 신청 (폼 답변 포함)
  - `GET /api/events/{eventId}/registrations/me` — 내 참가 신청 조회
  - `GET /api/events/{eventId}/registrations` — 참가자 목록 조회 (club ADMIN 이상)
- **DTO:** `CreateRegistrationRequestDto`, `CreateRegistrationResponseDto`, `MyRegistrationResponseDto`, `AdminRegistrationItemDto`, `RegistrationAnswerRequestDto`, `RegistrationAnswerResponseDto`
- **QR 토큰:** 참가 신청 시 UUID 기반 qrToken 발급

### 4. QR 체크인 / 출석 기능 (`eb8e728`)
- **엔티티:** `AttendanceLog` (registration, checkInTime, method)
- **API:**
  - `POST /api/attendance/check-in` — QR 코드로 체크인
- **로직:** qrToken으로 Registration 조회 → status를 `CHECKED_IN`으로 변경 → AttendanceLog 기록
- **DTO:** `CheckInRequestDto`, `CheckInResponseDto`

### 5. 패키지 구조 리팩토링 (`961ea32`)
- `service/`, `repository/` → `domain/service/`, `domain/repository/` 로 이동
- entity 클래스는 `domain/model/` 하위로 재배치
- 모든 import 경로 일괄 수정

### 6. 일정 관리 기능 (`fa96acd`)
- **API:**
  - `GET /api/calendar?year&month` — 월별 일정 조회 (내가 속한 동아리 행사를 동아리별 그룹으로 반환)
  - `GET /api/calendar/search?query` — 행사명·동아리명·장소명으로 검색
  - `GET /api/calendar/filter?startDate&endDate&eventName&clubName` — 복합 필터링
- **대상 범위:**
  - 월별 조회: `ClubMember` 기준 — 멤버인 동아리의 모든 행사
  - 검색/필터: `Registration` 기준 — `REGISTERED` 또는 `CHECKED_IN` 상태인 행사
- **DTO:** `CalendarClubGroupDto`, `CalendarEventItemDto`
- **Repository 쿼리 추가:** `EventRepository` (월별·검색·필터 JPQL), `RegistrationRepository` (상태별 eventId 조회)
- **기획 검토 사항:** `기획검토.md` 참고

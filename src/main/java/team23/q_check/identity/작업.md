# 로그인 / 회원가입 구현 작업 정리

## 개요

Discord OAuth2 기반 로그인 및 회원가입 기능을 구현했습니다.
JWT(access / refresh / signup)를 이용한 인증 체계를 추가하고, 기존 개발용 `X-USER-ID` 헤더 인증과 병행 동작하도록 설계했습니다.

---

## 구현된 엔드포인트

| 메서드 | 경로 | 설명 |
|--------|------|------|
| `GET` | `/auth/login` | Discord OAuth2 인증 페이지로 리다이렉트 |
| `GET` | `/auth/code?code=` | Discord 인가코드 콜백 처리 |
| `GET` | `/auth/nickname/check?nickname=` | 닉네임 중복 확인 |
| `POST` | `/auth/signup` | 회원가입 |
| `POST` | `/auth/refresh` | Access Token 갱신 |

### 로그인 플로우 (`/auth/login` → `/auth/code`)

1. `/auth/login` 요청 시 Discord OAuth2 URL로 리다이렉트
2. Discord 로그인 후 `/auth/code?code=...`로 인가코드 전달
3. 인가코드로 Discord access token 발급 → 닉네임, 이메일 조회
4. 이메일로 기존 회원 여부 확인
   - **기존 회원**: access JWT 반환 + refresh JWT를 `refresh_token` 쿠키에 설정
   - **신규 회원**: 10분 만료 signup JWT 반환 (`isNewUser: true`)

### `/auth/code` 응답 구조

```json
{
  "isNewUser": true,
  "token": "<signup JWT 또는 access JWT>"
}
```

### 회원가입 플로우 (`/auth/signup`)

- `Authorization: Bearer <signup JWT>` 헤더 필요
- 요청 바디: `name`(이름), `nickname`(닉네임), `email`(이메일)
- signup JWT 유효성 및 이메일 일치 여부 검증
- 닉네임 중복 확인
- 사용자 생성 후 access JWT 반환 + refresh JWT 쿠키 설정

## 신규 파일

### 설정

| 파일 | 설명 |
|------|------|
| `common/config/DiscordProperties.java` | Discord OAuth2 설정값 바인딩 |

| `common/config/PropertiesConfig.java` | `@EnableConfigurationProperties` 등록 |

### 인증 인프라

| 파일 | 설명 |
|------|------|
| `common/auth/JwtService.java` | JWT 발급 및 검증 (access / refresh / signup 3종) |

### Identity 모듈

| 파일 | 설명 |
|------|------|
| `identity/service/DiscordOAuthService.java` | Discord API 연동 (인가코드 교환, 사용자 정보 조회) |

| `identity/controller/AuthController.java` | `/auth/**` 엔드포인트 |

| `identity/dto/AuthCodeResponseDto.java` | 인가코드 콜백 응답 DTO |
| `identity/dto/AuthTokenResponseDto.java` | 인증 토큰 응답 DTO |
| `identity/dto/NicknameCheckResponseDto.java` | 닉네임 중복 확인 응답 DTO |

### DB 마이그레이션

| 파일 | 내용 |
|------|------|
| `V5__add_auth_fields_to_users.sql` | `users` 테이블에 `email`(unique), `refresh_token` 컬럼 추가 및 `username` unique 제약 추가 |

## 환경 변수

| 변수명 | 설명 |
|--------|------|
| `LOCAL_MYSQL_URL` | ex) `jdbc:mysql://localhost:3306/qcheck` |
| `LOCAL_MYSQL_USER` | MySQL 사용자명 |
| `LOCAL_MYSQL_PASSWORD` | MySQL 비밀번호 |
| `DISCORD_CLIENT_ID` | Discord 개발자 포털 앱의 Client ID |
| `DISCORD_CLIENT_SECRET` | Discord 개발자 포털 앱의 Client Secret |
| `DISCORD_REDIRECT_URI` | ex) `http://localhost:8080/auth/code` (Discord 앱 OAuth2 Redirects에 등록 필요) |
| `JWT_SECRET` | HMAC-SHA256 서명 키, 최소 32자 이상 |

## JWT 구조

| 종류 | subject | 추가 claim | 만료 |
|------|---------|-----------|------|
| access | userId | type=access | 1시간 |
| refresh | userId | type=refresh | 7일 |
| signup | email | type=signup, discordId, discordUsername | 10분 |

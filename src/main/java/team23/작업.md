# QCheck Backend - 완료된 기능 정리

## Auth `/auth`

| 메서드 | 경로 | 설명 | 인증 |
|--------|------|------|------|
| GET | `/auth/login` | Discord OAuth2 로그인 페이지로 리다이렉트 | 불필요 |
| GET | `/auth/code?code=` | Discord 인가코드 콜백. 기존 회원이면 access token 반환 + refresh token 쿠키 설정, 신규 회원이면 10분짜리 signup JWT 반환 | 불필요 |
| GET | `/auth/nickname/check?nickname=` | 닉네임 중복 확인 | 불필요 |
| POST | `/auth/signup` | 회원가입. `Authorization: Bearer <signup JWT>` 헤더 필요. 성공 시 access token 반환 + refresh token 쿠키 설정 | 불필요 |
| POST | `/auth/refresh` | `refresh_token` 쿠키로 access/refresh token 재발급 | 불필요 |

| 메서드 | 경로 | 설명 | 인증 |
|--------|------|------|------|
| GET | `/api/users/me` | 내 프로필 조회 (id, username, realName) | 필요 |

## Club `/api/clubs`

| 메서드 | 경로 | 설명 | 인증 |
|--------|------|------|------|
| POST | `/api/clubs` | 클럽 생성. 생성자는 자동으로 OWNER | 필요 |
| GET | `/api/clubs` | 내가 속한 클럽 목록 조회 (역할 포함) | 필요 |
| GET | `/api/clubs/{clubId}/members` | 클럽 멤버 목록 조회 | 필요 (멤버) |
| POST | `/api/clubs/{clubId}/members` | 클럽 멤버 추가 | 필요 (OWNER/ADMIN) |
| PUT | `/api/clubs/{clubId}/members/{memberId}/role` | 멤버 역할 변경. ADMIN은 OWNER 역할 부여 불가 | 필요 (OWNER/ADMIN) |

## Event `/api/events`

| 메서드 | 경로 | 설명 | 인증 |
|--------|------|------|------|
| POST | `/api/events` | 이벤트 생성. 커스텀 폼 필드 포함 가능 | 필요 (OWNER/ADMIN) |
| GET | `/api/events?page=&size=` | 이벤트 목록 페이지네이션 조회 | 불필요 |
| GET | `/api/events/{eventId}` | 이벤트 상세 조회 (폼 필드 포함) | 불필요 |
| PUT | `/api/events/{eventId}` | 이벤트 수정 | 필요 (OWNER/ADMIN) |
| POST | `/api/events/{eventId}/registrations` | 이벤트 등록. QR 토큰 발급 | 필요 |
| GET | `/api/events/{eventId}/registrations/me` | 내 등록 정보 조회 (QR 토큰, 폼 답변 포함) | 필요 |
| GET | `/api/events/{eventId}/registrations` | 이벤트 전체 등록자 목록 조회 | 필요 (OWNER/ADMIN) |

## Attendance `/api/attendance`

| 메서드 | 경로 | 설명 | 인증 |
|--------|------|------|------|
| POST | `/api/attendance/check-in` | QR 토큰으로 출석 체크. 등록 상태를 CHECKED_IN으로 변경하고 AttendanceLog 생성 | 필요 (OWNER/ADMIN) |

---

## 인증 방식

- **JWT Bearer**: `Authorization: Bearer <access token>` — 프로덕션
- **X-USER-ID 헤더**: 개발용 fallback (JWT가 없을 때만 사용)
- **refresh token**: `refresh_token` HTTP-only 쿠키

## 역할 체계 (ClubRole)

| 역할 | 권한 |
|------|------|
| OWNER | 모든 권한 |
| ADMIN | 이벤트 생성/수정, 멤버 관리 (OWNER 제외) |
| MEMBER | 이벤트 조회 및 등록 |

## 등록 상태 (RegistrationStatus)

`REGISTERED` → `CHECKED_IN` / `CANCELED`
